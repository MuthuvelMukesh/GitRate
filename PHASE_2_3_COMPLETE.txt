HOW TO RUN TESTS
═══════════════════════════════════════════════════════════════════════════════

BASIC COMMANDS:
  pytest tests/                         # Run all tests
  pytest tests/ -v                      # Verbose output
  pytest tests/ --cov=.                 # With coverage report
  pytest tests/ --cov-report=html       # HTML coverage report

BY CATEGORY:
  pytest tests/unit/                    # Unit tests only
  pytest tests/integration/             # Integration tests only
  pytest tests/ -m unit                 # By marker

SPECIFIC TESTS:
  pytest tests/unit/test_models.py      # Specific file
  pytest tests/unit/test_models.py::TestRepositoryInfo  # Specific class
  pytest tests/unit/test_models.py::TestRepositoryInfo::test_valid_creation  # Specific test

ADVANCED:
  pytest tests/ -vv --tb=long           # Maximum detail
  pytest tests/ -n auto                 # Parallel execution
  pytest tests/ -x                      # Stop on first failure
  pytest tests/ -k "test_cache"         # Run tests matching pattern
