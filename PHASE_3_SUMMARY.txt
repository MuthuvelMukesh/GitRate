## Scoring System

```
OVERALL SCORE = 
    IP & Legal (30%) +
    Security (25%) +
    Code Quality (25%) +
    Team Sustainability (20%)
```

Each component uses mixed scoring methods:
- **Penalty-based:** CRITICAL (-25), HIGH (-10), MEDIUM (-5), LOW (-3)
- **Weighted criteria:** Pass/fail criteria with configurable weights
- **Hybrid:** Combines multiple methods for accuracy

**Range:** 0-100 (continuous float)

async def _audit_code_quality(self, repo_data):
    try:
        auditor = CodeQualityAuditor()
        score, findings = await auditor.run(repo_data)
        return score, findings
    except Exception as e:
        logger.error(f"Code Quality audit failed: {e}")
