## Technical Specifications

### PDF Report Sections

```
Page 1:   Cover Page
Page 2-3: Executive Summary with Key Metrics
Page 4:   Score Overview by Category
Page 5-6: Critical Findings (if any)
Page 7-8: Detailed Findings by Category
Page 9:   Remediation Roadmap Overview
Page 10:  Risk Assessment & Recommendation
```

### Roadmap Scheduling Algorithm

1. **Prioritize** findings by severity + hours
2. **Group** into 5-20 hour tasks
3. **Schedule** across 13-week window
4. **Flag** at-risk tasks (exceeds capacity)
5. **Track** dependencies between tasks

### Report Output Formats

| Report Type | Format | Size | Use Case |
|-------------|--------|------|----------|
| PDF Report | PDF | 250-400 KB | Due diligence documentation |
| Certificate | PDF | 80-120 KB | Executive sign-off |
| Roadmap | JSON/List | <10 KB | Project planning |

## Example Usage

### Generate All Reports

```python
from core.audit_engine import AuditEngine

# Run audit
engine = AuditEngine(github_token="...")
audit_result, error = await engine.run_full_audit("kubernetes", "kubernetes")

# Generate all reports
reports = await engine.generate_all_reports(audit_result, team_size=3)

# Save reports
with open(reports["pdf"]["filename"], "wb") as f:
    f.write(reports["pdf"]["content"])

with open(reports["certificate"]["filename"], "wb") as f:
    f.write(reports["certificate"]["content"])

# Show roadmap
print(reports["roadmap"]["summary"])
for task in reports["roadmap"]["tasks"]:
    print(f"Week {task.week}: {task.title} ({task.estimated_hours}h)")
```
