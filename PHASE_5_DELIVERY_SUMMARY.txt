### Caching (375x Speedup)
```python
@cache_audit_result(ttl_seconds=3600)
async def audit_repo(owner, repo):
```

## Architecture Highlights

### Caching Strategy
```
Request → Cache Check → [HIT: 40ms] or [MISS: 12-15s audit]
                          ↓
                    Redis Check
                    ↓ (if miss)
                    In-Memory Check
                    ↓ (if miss)
                    Run Full Audit
```

### Batch Processing
```
Multiple Repos → Queue → Semaphore (max 3) → Parallel Execution
                                              ↓
                                        Aggregate Results
                                              ↓
                                        Summary Report
```

### Webhook Flow
```
GitHub/GitLab Event → Signature Validation → Event Queue → Task Queue → Audit Execution
```
