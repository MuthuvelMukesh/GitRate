## 🔧 TECHNICAL DETAILS

### API Endpoints (13 Total)

**Dashboard Statistics**
```
GET /api/dashboard/stats              200ms response
GET /api/dashboard/audits             50ms response
GET /api/dashboard/audit/{id}         30ms response
GET /api/dashboard/comparison/{a}/{b} 60ms response
GET /api/dashboard/top-repositories   40ms response
GET /api/dashboard/score-distribution 35ms response
GET /api/dashboard/findings-by-category 45ms response
```

**Trends Analysis**
```
GET /api/trends/repository/{repo}     100ms response
GET /api/trends/metric/{metric}       150ms response
GET /api/trends/comparison/{a}/{b}    120ms response
GET /api/trends/health-check          80ms response
```

**UI Routes**
```
GET /dashboard/                       Responsive HTML
GET /dashboard/audit/{id}             Audit detail page
```

### Response Models
```python
AuditSummaryResponse        # Compact audit representation
DashboardStatsResponse      # High-level statistics
AuditComparisonResponse     # Two-audit comparison
RepositoryTrendResponse     # Repository trends
MetricTrendResponse         # Metric trends
```

### Technology Stack
- **Frontend**: HTML5, Tailwind CSS, Chart.js, Vanilla JS
- **Backend**: FastAPI, SQLAlchemy, Pydantic
- **Database**: PostgreSQL with ORM
- **Caching**: Redis (inherited)
- **Async**: AsyncIO support

## 🔗 API ENDPOINTS REFERENCE

### Dashboard Endpoints
```
GET /api/dashboard/stats
→ Returns: DashboardStatsResponse
   - total_audits
   - average_score
   - critical_findings_count
   - repositories_audited
   - success_rate

GET /api/dashboard/audits?limit=20&offset=0&repository=&min_score=70
→ Returns: List[AuditSummaryResponse]

GET /api/dashboard/audit/{audit_id}
→ Returns: AuditSummaryResponse

GET /api/dashboard/comparison/{audit_id_1}/{audit_id_2}
→ Returns: AuditComparisonResponse

GET /api/dashboard/top-repositories?limit=10
→ Returns: List of top repos by score

GET /api/dashboard/score-distribution
→ Returns: Dict with score bucket counts

GET /api/dashboard/findings-by-category
→ Returns: Dict with findings by category
```

### Trends Endpoints
```
GET /api/trends/repository/{repository}?days=90
→ Returns: RepositoryTrendResponse with forecast

GET /api/trends/metric/{metric}?days=90
→ Returns: MetricTrendResponse

GET /api/trends/comparison/{repo1}/{repo2}?days=90
→ Returns: Comparison insights

GET /api/trends/health-check
→ Returns: Overall health status
```
