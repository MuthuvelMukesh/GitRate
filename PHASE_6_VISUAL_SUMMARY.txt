## 🚀 QUICK START

```bash

# 2. Open dashboard
open http://localhost:8000/dashboard/

# 3. Check API
curl http://localhost:8000/api/dashboard/stats

# 4. View API documentation
open http://localhost:8000/docs

├─ 🔍 Filter controls
├─ 📋 Recent audits table
└─ ⏱️ Auto-refreshing every 60 seconds
```
