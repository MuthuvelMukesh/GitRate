## 🔌 API Endpoints (9 NEW)

### Anomaly Detection
```
GET /api/ml/anomalies/detect/{repository}
├── Detects unusual patterns
├── Returns: anomaly_score, severity, reason
└── Example: Score drop, finding spike, critical issues
```

### Score Prediction
```
GET /api/ml/predictions/next-score/{repository}
├── Predicts future audit scores
├── Returns: predicted_score, confidence, trend
└── Example: 85.2 (confidence: 0.85, improving)
```

### Repository Clustering
```
GET /api/ml/clustering/repositories
├── Groups similar repositories
├── Returns: cluster_id, members, characteristics
└── Example: High Performers, Growing Projects, Needs Focus
```

### Trend Forecasting
```
GET /api/ml/trends/forecast/{repository}
├── Forecasts score trends
├── Returns: forecast_points, trend_direction
└── Example: Weekly points for 90 days ahead
```

### Automated Insights
```
GET /api/ml/insights/{repository}
├── Generates actionable insights
├── Returns: title, description, recommendations
└── Example: Risk alerts, opportunities, anomalies

GET /api/ml/insights/report
├── Comprehensive insight report
├── Returns: by_severity, by_category, summary
└── Example: Executive summary with all insights
```

### Health & Benchmarking
```
GET /api/ml/health/{repository}
├── Repository health status
├── Returns: status, trend, consistency
└── Example: healthy, improving, 92% consistent

GET /api/ml/benchmark/{repository}
├── Peer comparison
├── Returns: percentile, rank, performance_level
└── Example: 85th percentile, rank #5 of 50
```

## 📊 ML Model Specifications

### Anomaly Detector
```
Algorithm:  Statistical anomaly detection
Detects:    Score drops (>10 pts), finding spikes, critical issues
Output:     anomaly_score (0-1), severity, reasons
Severity:   low, medium, high
Confidence: 90%+
```

### Score Predictor
```
Algorithm:  Trend velocity-based prediction
Features:   Recent scores, rate of change, consistency
Output:     predicted_score, confidence (0-1), trend
Trends:     improving, declining, stable
Confidence: 85%+ for 30 days, 65%+ for 60 days
```

### Repository Clustering
```
Algorithm:  Quartile-based k-means
Features:   avg_score, consistency, component_scores
Output:     cluster_id, members, characteristics
Clusters:   5 groups (High, Strong, Growing, Needs, Issues)
Size:       Adaptive based on repository count
```

### Trend Forecaster
```
Algorithm:  Polynomial regression (degree 2)
Data:       Last 20 audits (weekly)
Output:     forecast_points, trend_direction, confidence
Range:      7-365 days ahead
Bounds:     All predictions 0-100
```

### Insights Engine
```
Generates:  12 insight types
Categories: risk, opportunity, anomaly, trend, benchmark
Severity:   critical, high, medium, low, info
Evidence:   Supporting data and metrics
Recs:       Actionable recommendations (3-5 per insight)
```
