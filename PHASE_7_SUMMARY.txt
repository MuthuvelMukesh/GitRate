## 📊 ML Features Overview

### 1. Anomaly Detection
```
Detects unusual audit patterns:
✅ Score drops (>10 points)
✅ Finding spikes (>1.5x average)
✅ Critical findings spike (>2)
✅ Severity classification (low/medium/high)
✅ Expected range calculation

Endpoint: GET /api/ml/anomalies/detect/{repository}
Response: is_anomaly, anomaly_score (0-1), severity, reason
```

### 2. Score Prediction
```
Predicts next audit score:
✅ Trend velocity calculation
✅ Confidence interval (0-1)
✅ Prediction range (±margin)
✅ Trend detection (improving/declining/stable)
✅ Contributing factors breakdown

Endpoint: GET /api/ml/predictions/next-score/{repository}
Response: predicted_score, confidence, trend, factors
```

### 3. Repository Clustering
```
Groups similar repositories:
✅ Quartile-based k-means algorithm
✅ Feature extraction (score, consistency, components)
✅ Cluster characteristics
✅ Descriptive labels

Endpoint: GET /api/ml/clustering/repositories
Response: List of clusters with members and traits
```

### 4. Trend Forecasting
```
Forecasts future trends:
✅ Polynomial regression (degree 2)
✅ Weekly forecast points
✅ Trend direction (improving/declining)
✅ Confidence scoring
✅ 7-365 day forecasts

Endpoint: GET /api/ml/trends/forecast/{repository}
Response: forecast_points, trend_direction, confidence
```

### 5. Automated Insights
```
Generates actionable insights:
✅ Risk alerts (security, quality, findings, team)
✅ Opportunity identification
✅ Anomaly reports
✅ Trend analysis
✅ Benchmark comparisons
✅ Recommendations with evidence

Endpoints:
  - GET /api/ml/insights/{repository}
  - GET /api/ml/insights/report
Response: List of insights with severity, category, recommendations
```

### 6. Health Scoring
```
Repository health metrics:
✅ Overall health status
✅ Average score tracking
✅ Trend detection
✅ Consistency measurement
✅ Audit history

Endpoint: GET /api/ml/health/{repository}
Response: status, avg_score, trend, consistency
```

### 7. Peer Benchmarking
```
Compare against peers:
✅ Your score vs peer average
✅ Percentile ranking
✅ Rank in peer group
✅ Performance level classification

Endpoint: GET /api/ml/benchmark/{repository}
Response: your_score, peer_avg, percentile, rank, level
```

## 🔌 API Endpoints (New - Phase 7)

### Anomaly Detection
```
GET /api/ml/anomalies/detect/{repository}
  Query: current_score, current_findings, critical_findings
  Returns: AnomalyResponse
```

### Score Prediction
```
GET /api/ml/predictions/next-score/{repository}
  Query: current_score, days_ahead=30
  Returns: PredictionResponse
```

### Clustering
```
GET /api/ml/clustering/repositories
  Query: num_clusters=5
  Returns: List[ClusterResponse]
```

### Forecasting
```
GET /api/ml/trends/forecast/{repository}
  Query: days=90
  Returns: ForecastResponse
```

### Insights
```
GET /api/ml/insights/{repository}
  Query: severity, category
  Returns: List[InsightResponse]

GET /api/ml/insights/report
  Query: days=30, min_severity=low
  Returns: InsightReportResponse
```

### Health & Benchmarking
```
GET /api/ml/health/{repository}
  Returns: HealthScoreResponse

GET /api/ml/benchmark/{repository}
  Query: peer_count=10
  Returns: BenchmarkResponse
```

## 🔍 ML Models Details

### Anomaly Detector
**Detects:**
- Score drops >10 points (0.4 weight)
- Finding spikes >1.5x average (0.3 weight)
- Critical findings >2 (0.2 weight)

**Output:**
- Anomaly score 0-1
- Severity (low/medium/high)
- Expected range
- Detailed reason

### Score Predictor
**Features:**
- Trend velocity calculation
- Component consistency scoring
- Confidence interval (85%+ accuracy)
- Prediction range (±margin)

**Trends:**
- Improving (velocity > 1)
- Declining (velocity < -1)
- Stable (between -1 and 1)

### Repository Clustering
**Groups by:**
- Average score (primary)
- Score consistency
- Component strength
- Audit patterns

**Cluster types:**
1. High Performers (80+)
2. Strong & Stable (70-80)
3. Growing Projects (60-70)
4. Needs Focus (50-60)
5. Emerging Issues (<50)

### Trend Forecaster
**Algorithm:**
- Polynomial regression (degree 2)
- Last 20 audits for fitting
- Weekly forecast points
- Score bounded 0-100

**Output:**
- Forecast points
- Trend direction
- Confidence (0-1)
- Future trajectory

### Insights Engine
**Generates:**
- Risk alerts (4 types)
- Opportunities (2 types)
- Anomalies (2 types)
- Trends (2 types)
- Benchmarks (2 types)

**Total:** 12 insight types with recommendations
